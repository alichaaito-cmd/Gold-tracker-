# Gold Lot Tracker — no API key required

This version is designed so you do NOT need to create or enter any API key.

It uses the public Gold API endpoint:
https://api.gold-api.com/price/XAU

Features:
- Live indicative gold spot in USD/troy ounce
- Unlimited purchase lots
- kg / grams / troy ounces
- 999.9 / 999 / 995 / 916 / 750 / custom purity
- Purchase spot price and optional fees
- Per-lot value, P/L, P/L %, fine ounces and break-even
- Portfolio totals
- Automatic refresh about every 60 seconds while open
- Backup / restore
- Installable on iPhone Home Screen after hosting over HTTPS

To install on iPhone after hosting:
1. Open the app URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Enable Open as Web App if shown.
5. Tap Add.
